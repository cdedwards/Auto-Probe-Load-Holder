# Auto-Probe-Load-Holder
36mm round probe auto mount holder. 2 m5 bolts, 2 m3 bolts, 2 heatset inserts of voron spec, 2 threaded inserts for wood.

A 40mm round spring of 30mm height is also required. Aliexpress has them. Once I recieve my order I can verify if everything works as it should.
The ER nut might need a chamfer where the threads are. And the nut socket will also need one eventually. Everything appears to work as expected.

Macros will be needed which define the location, z height, spindle speed as it lowers/raises when this tool is selected. I'll be using tool 99 for this probe on my own system.
